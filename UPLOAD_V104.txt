PASSO 1 — FIREBASE
-------------------

1. Abra Firebase → Firestore Database → Regras no projeto correto.
2. Substitua o texto pelo `firestore.rules` de `ATUALIZACAO_ATUAL_V104`.
3. Clique em Publicar.
4. Confirme que existem os blocos de `config_financeiro`, `clientes_ciclo_financeiro`, `financeiro_lancamentos` e `contatos_clientes_financeiro`.

PASSO 2 — GITHUB
-----------------

1. Abra `ATUALIZACAO_ATUAL_V104`.
2. Envie para a raiz do repositório todos os arquivos publicáveis listados no manifesto, preservando as pastas.
3. Não envie `rollback_v103`, ZIP, memória privada, `node_modules`, logs do emulador ou evidências privadas.
4. Faça o commit na `main` e aguarde o Pages.
