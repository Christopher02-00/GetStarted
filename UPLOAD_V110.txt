- impede respostas atrasadas de repovoarem o perfil errado;

- restaura corretamente as telas do Chris e os links após voltar da Cecília.

GITHUB
------

1. Abra a pasta ATUALIZACAO_ATUAL_V110.
2. Use MANIFESTO_SHA256_V110.txt como lista autoritativa.
3. Envie todos os arquivos do manifesto, exceto os dois dentro de rollback_v109.
4. Envie também MANIFESTO_SHA256_V110.txt.
5. Preserve todos os caminhos, especialmente scripts/.
6. Não envie rollback_v109, o ZIP, node_modules, logs, capturas ou memória privada.
7. Aguarde o GitHub Pages e recarregue sem cache.
8. Confirme o build V110 antes de validar a jornada.

FIREBASE
--------

Não publique nada no Firebase para a V110. O firestore.rules está byte a byte
igual à V109 e foi incluído somente para manter o pacote completo.

-----------------------

1. Entre como Chris e confirme que Central de Vendas e Financeiro aparecem.
2. Troque para Amanda: Central de Vendas, Financeiro e Projetos Avulsos antigos
   devem desaparecer; Central de Clientes e Contratos autorizados permanecem.

4. Troque para Cecília: nos links para clientes, somente Calendários deve ficar.
5. Volte para Chris: os links autorizados precisam retornar sem reload.
6. Recarregue sem cache e repita a troca uma vez.

O QUE NÃO FAZER
---------------

- não publicar regra no Firebase;
- não executar migração ou saneamento de dados;
- não alterar Fedalto, Joaquim/Açougue, mensalidades ou contatos;
- não interpretar esta V110 como o redesenho completo da Central de Vendas.
