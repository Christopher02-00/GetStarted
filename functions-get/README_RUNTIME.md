# Operação Get

Node 22; código único get-operacao. Os quatro serviços compartilham o mesmo motor. Copie runtime.example.env para .env.get-started-4956d antes de publicar com Firebase CLI pelo firebase.json da raiz. Nenhuma credencial privada é incluída.

O perfil de serviço existente usa a identidade gerenciada do Firebase. A agenda, a aprovação, a edição e a programação têm habilidades separadas em programacao_config_i165/ativo. A troca editorial depende do documento explícito processo_calendarios_i164/ativo; a data não a ativa. Não criar esse documento por inferência nem restaurar dados antigos.

A integração UploadPost permanece desligada até conectar as contas e configurar o serviço. Arquivos privados usam manifesto, geração e hash; os links temporários não devem ser persistidos. E-mail está desabilitado; push exige registro Google do próprio aparelho. O endpoint de diagnóstico temporário foi removido.
